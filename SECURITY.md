# Security Policy

## Reporting a vulnerability

Please report suspected security issues privately rather than opening a public GitHub issue.

Include:
- a clear description of the vulnerability
- affected component or endpoint
- reproduction steps or proof of concept
- potential impact

Do not include real credentials, production tokens, or private user data in reports.

## Supported scope

Security reports are welcome for the current default branch and for vulnerabilities that are reproducible from the repository's documented setup.

Once a report is confirmed, remediation will be prioritized based on exploitability and impact.
